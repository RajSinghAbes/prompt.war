STUDENT TASK MANAGER

Requirements:
- Node.js installed
- VS Code (optional)

How to run:
1. Extract this ZIP file.
2. Open the StudentTaskManager folder in VS Code.
3. Open the terminal in this folder.
4. Run: npm install
5. Run: npm start
6. Open http://localhost:4000 in your browser.

Features:
- Add tasks
- View tasks
- Delete tasks

Technologies:
- HTML and CSS: page structure and styling
- JavaScript: frontend functionality
- Node.js and Express: backend and API

Note:
Tasks are stored in server memory. They reset when the server restarts.
